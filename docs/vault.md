# shio 密码库

一个纯本地、多密码库的 Android 密码管理器。数据由 [shio](https://github.com/) 内核以加密方式落盘，不联网、不上传、不依赖任何云服务。

- 包名：`top.zxionf.shio`（debug 构建带 `.debug` 后缀）
- 版本：`0.1.5`（versionCode 3）
- 最低系统：Android 10（API 29），目标 API 37

## 功能

### 多密码库

- 可以创建多个互相独立的库（例如「工作」「个人」），每个库有自己的主口令。
- 库列表显示名称、创建时间与「上次打开」标记；支持重命名与删除（删除会先要求确认）。
- 启动分流：没有库进创建页；只有一个库直接进该库解锁页；有多个库先进库列表。
- 升级前的老库 `vault.db` 会自动出现在列表里（名称「默认密码库」），文件原地保留、不迁移。

### 主口令

- 创建时设置，至少 8 个字符。**忘记口令无法恢复数据**，也没有后门。
- 支持随时修改主口令（设置 → 安全 → 修改主口令）：内核只重新包裹密钥，不重写条目，改完旧口令立即失效。
- 口令只在内存中短暂存在：调用内核前转成字节数组，用完清零。

### 条目管理

- 字段：标题（必填）、用户名、密码（必填）、连接、备注。
- 新建 / 编辑 / 删除；有未保存修改时返回会提示「放弃修改？」。
- 保存后列表与详情立即刷新。

### 搜索与筛选

- 搜索匹配标题、用户名、连接、备注，忽略大小写（密码不参与搜索，避免被探测）。
- 筛选：只看收藏、按标签筛选（可多选，取「同时包含」），与搜索可叠加。

### 标签与收藏

- 标签是独立实体：在设置 → 数据 → 管理标签里新建、重命名、删除；删除时提示受影响的条目数。
- 条目可勾选多个标签（编辑器的「标签」行）。
- 收藏是条目自身的标记，列表项标题前显示星标。

### 密码生成器

- 长度 12–64（默认 20），可分别开关大写 / 小写 / 数字 / 符号，可排除易混淆字符（`I l 1 O 0 o 5 S 8 B 2 Z`）。
- 使用 `SecureRandom`；每个勾选的字符集至少出现一次，最后整体打乱，避免前几位固定。
- 在密码字段的弹层里打开，「使用此密码」直接写回字段，不直接落库。

### 剪贴板

- 复制用户名 / 密码 / 连接 / 备注时标记为敏感内容（API 33+），剪贴板浮层与输入法联想不展示明文。
- **30 秒后自动清除**；锁定时立即清除；只清自己写入的那条，不会误删用户后来复制的其它内容。
- 输入法自带的「剪贴板历史」属其私有存储，应用无法删除；首次复制会提示一次并给出跳转输入法设置的入口。

### 导入导出

- 导出 CSV / JSON（含明文密码，界面会提示妥善保管）。
- 导入只新增、不覆盖：结果提示「新增 N 条，跳过 M 条」；缺标题或密码的行会被跳过。
- 导入导出暂不含标签与收藏。

### 备份与恢复

- 备份：把当前库在线复制成一个文件（用**当前主口令**加密），可保存到任意位置。
- 恢复：选择备份文件 → 输入该备份当时的主口令 → 替换当前库全部内容；成功后会要求用备份口令重新解锁。
- 恢复失败（口令错、文件损坏）时**现有数据不变**，可以继续使用；失败不会留下半成品文件。

### 自动锁定

- 可选「立即 / 1 分钟 / 5 分钟 / 15 分钟」，默认立即。
- 旋转屏幕不算切后台；打开系统文件选择器（备份/导入导出）期间有 120 秒宽限，避免流程被自己锁断。
- 锁定会销毁内核句柄并清空会话，回到解锁页；手动锁定（列表页锁图标）走同一条路径。

### 外观

- 主题：跟随系统 / 浅色 / 深色。
- 颜色：动态取色（Android 12+）与 5 套预设色板（Shio 蓝、青、绿、紫、橙）。
- 选择立即生效并持久化，重启后保持。
- 全应用统一使用 Material 3 Expressive 设计风格。

### 诊断信息

- 设置 → 关于 → **长按「版本」** 打开诊断弹窗：存储格式（`format=2`）、同步身份（`db_id`）、设备身份（`device_id`）、内核版本、ABI 版本、数据库路径，可一键复制。

## 安全与隐私

| 项 | 做法 |
|---|---|
| 网络 | **不申请任何网络权限**，无统计、无崩溃上报、无账号 |
| 存储 | 数据由内核加密落盘；元数据（库名、文件名）不加密但不含敏感内容 |
| 截屏 | release 构建启用 `FLAG_SECURE`，禁止截屏、录屏与最近任务预览 |
| 备份通道 | `allowBackup=false` + 数据提取规则全排除，云备份与换机迁移不会带走数据库 |
| 日志 | 全仓零日志调用（含 JNI），条目正文、口令、复制内容不会进日志 |
| 外链 | 只有 `http`/`https` 且带主机名的地址才能外部打开（拒绝 `javascript:`/`file:`/`intent:`） |
| 密码显隐 | 详情页密码默认隐藏，离开页面或旋转即复位 |

## 系统要求与产物

- Android 10（API 29）及以上；ABI `arm64-v8a`、`x86_64`。
- release 开启 R8 与资源压缩，APK 约 8.8 MB；`.so` 按 16 KB 页对齐构建（Android 15+ 设备要求）。

## 技术要点

- 模块：`shio-vlt`（本应用）、`shared`（JNI 包装与内核封装，供未来应用复用）、`shio-todo`（待办应用占位）。
- UI：Kotlin + Jetpack Compose + Material 3 Expressive + Navigation Compose，单 Activity。
- 内核：Rust 实现的 shio，经 JNI 薄层调用；写入以单条/批量提交，Android 上通过旁路 `<db>.lock` 保证单写。
- JSON：系统 `org.json`；偏好用 `SharedPreferences`；不引入 DI 框架与序列化库。
- 首次建库即启用同步身份（`format=2`，不可回退），但**当前版本没有同步 UI、配对与网络传输**。

## 不在当前版本

- 生物识别解锁、Autofill、TOTP
- 多端同步（内核能力已就绪，应用侧未接入）
- 条目跨库移动、库导入到另一台设备
- 导入导出携带标签/收藏
