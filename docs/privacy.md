# 隐私说明

适用应用：shio 密码库（`top.zxionf.shio`，debug 构建为 `top.zxionf.shio.debug`）。
本文件用于商店隐私说明，也是代码侧的核对依据；修订时两边必须同步。

## 一句话

shio 是本机单机应用：**不申请网络权限，不上传任何数据，不含统计、广告与崩溃上报 SDK**。

## 我们收集什么

**不收集任何数据。** 应用没有账号体系，没有遥测，没有第三方 SDK 的埋点。

## 数据存在哪里

- 密码库数据由内核加密后写在应用私有目录 `files/vaults/<uuid>.db`（旧版为 `files/vault.db`），
  加密密钥由你设置的主口令派生。
- 加密库文件之外只有元数据（库名、文件名），不含条目正文。
- `allowBackup=false` 且数据提取规则全排除：系统云备份与换机迁移不会带走数据库。

## 网络

- 应用**不申请网络权限**。release 产物的权限清单里只有系统自动加入的
  `top.zxionf.shio.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION`（应用内部广播用，不涉及用户数据）。
- 没有联网能力，因此不存在“上传”“同步”“上报”这类行为。

## 权限与系统交互

| 能力 | 使用方式 |
|---|---|
| 文件选择器（SAF） | 仅在你主动点“导出 / 导入 / 备份 / 恢复”时打开，用于读写你选定的文件 |
| 外部浏览器 | 仅当条目网址是 `http` / `https` 时才能跳转打开 |
| 剪贴板 | 复制敏感字段后 30 秒或锁定时自动清除，且只清应用自己写入的那条 |

当前版本不含生物识别与自动填充；若后续引入，只在设备本地校验，不上传任何信息。

## 你自己选择交出去的数据

导出（CSV / JSON）与备份（`.db` 文件）都把内容写到**你选定的位置**，内容为你自己选择的明文或加密副本，
由你自行保管。应用不保留这些文件的副本。

## 截屏与最近任务

release 构建启用 `FLAG_SECURE`，禁止截屏、录屏与最近任务预览。

## 日志

全仓零日志调用（含 JNI 层），条目正文、口令与复制内容不会写入日志。

## 联系方式

问题与建议请发到仓库 issue：`https://github.com/`（与 `docs/vault.md` 保持一致）。
